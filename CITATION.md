# Citation Guide

Edition label: `2026-10`

Use the public title exactly as published:

- Research Publications: `National Security Power and Constitutional Imbalance`
- Legislation: `EFTA II Memo`

How to cite:

- Cite the specific edition and patch ID if one exists.
- Cite the permanent URL for the exact edition, not the movable `latest` pointer.
- Include the artifact hash when referencing downloadable files.

Required attribution fields:

- title
- edition ID
- version or patch ID
- license: CC BY 4.0
- canonical URL

Do not cite internal program labels, milestone names, or unpublished working titles.
